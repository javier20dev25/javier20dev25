## 👨‍💻 Sobre Mí

Hola, soy **Javier** (alias `@javier20dev25`), investigador de seguridad, desarrollador de software y funcionario público aduanero en Nicaragua:

- 💻 **Desarrollo & Ciberseguridad**: Programando activamente desde **2019**, con especialización en **seguridad en la cadena de suministro (Supply Chain Security), SAST heurístico, detección de malware encubierto en paquetes npm/PyPI, análisis AST y modelos de inferencia forense**.

## 🛡️ Ecosistema Sentinel

Diseñado y desarrollado por **NIGHTTRACE Security Intelligence**, **Sentinel** es un ecosistema defensivo integral enfocado en proteger el ciclo de vida del software contra ataques a la cadena de suministro, malware en dependencias de terceros e inyecciones de código malicioso en Pull Requests.

| Componente | Tipo | Descripción | Enlaces & Disponibilidad |
|---|---|---|---|
| **Sentinel Cloud** | `SaaS / Web Platform` | Plataforma cloud de auditoría continua en GitHub. Escaneo automatizado de PRs mediante AST + firmas, grafos de evidencia causal, exportación estándar **SARIF v2.1.0** y atestaciones de cumplimiento **ISO 27001 / SOC 2**. | 🌐 **[Web en Producción](https://sentinel-psi-nine.vercel.app/)**<br>💳 **[Ver Planes de Suscripción](https://sentinel-psi-nine.vercel.app/)** |
| **Sentinel CLI** | `Terminal / CI Engine` | Motor local de ejecución y gobernanza de dependencias. Bloqueo de ejecuciones arbitrarias, verificación criptográfica de integridad de lockfiles, detección de typosquatting y telemetría de amenazas local. | 📦 **[Repositorio GitHub](https://github.com/javier20dev25/sentinel-cli)** |
| **Sentinel Oracle** | `AI Assistant / Core` | Asistente de seguridad inteligente multi-proveedor (OpenAI, Anthropic, Gemini, Groq, Ollama), integración nativa **MCP (Model Context Protocol)**, módulo SecuriGit y correlación heurística. | 🔮 **[Repositorio GitHub](https://github.com/javier20dev25/sentinel-oracle)** |
| **Sentinel Decoys & Labs** | `Canary Network` | Señuelos activos, canarios de credenciales y repositorio de simulaciones de evasión para evaluación de defensas. | 🧪 **[Decoys](https://github.com/javier20dev25/sentinel-decoys)** · **[Simulaciones](https://github.com/javier20dev25/sentinel-simulaciones)** |
